# Impossible Cloud

> Impossible Cloud is a European sovereign cloud platform headquartered in Hamburg, Germany. It provides S3-compatible object storage (from €7.99 per TB/month, no egress or API fees), bare metal GPU servers (NVIDIA, from €2.60 per GPU card-hour), and managed AI services. All services are GDPR-ready by design, operated under EU jurisdiction with no US CLOUD Act exposure, and certified to ISO/IEC 27001 with SOC 2 and PCI DSS certified data centers.

Key facts:

- Founded in 2021, headquartered in Hamburg, Germany (Friesenweg 12, Haus 5, 22763 Hamburg)
- European data sovereignty: data stays under EU jurisdiction, no non-European sub-processors
- S3-compatible object storage with 99.999999999% (11 nines) durability and Object Lock (WORM) support
- Transparent pricing: no egress fees, no API call charges, no minimum commitments, no lock-in periods
- 50+ integrations with backup and cloud solutions, including Veeam, Acronis, MSP360, NAKIVO, and Hornetsecurity
- 3,000+ enterprise customers, 200+ experts across Europe and globally
- Contact: info@impossiblecloud.com

## Products

- [Object Storage](https://www.impossiblecloud.com/s3-storage): S3-compatible cloud object storage from €7.99 per TB/month with no egress or API fees, 11 nines durability, and Object Lock for immutable backups
- [Bare Metal GPU](https://www.impossiblecloud.com/baremetal): Dedicated NVIDIA GPU servers without virtualization or resource sharing, from €2.60 per GPU card-hour
- [AI Services](https://www.impossiblecloud.com/ai-services): Fully managed LLM inference, model deployments, managed Kubernetes, and HPC
- [Backup Solutions](https://www.impossiblecloud.com/backup-solutions): Cloud storage for backup and disaster recovery with leading backup software integrations
